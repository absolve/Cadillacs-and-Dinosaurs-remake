# 武器与道具

## 结论（TL;DR）

- **弹药是 ROM 实值**：步枪 / 手枪 / 霰弹枪 6 发，**乌兹 / M16 是 48 发**（不是 6），火箭筒 4 发；枪打空后可捡起当近战武器或投掷。
- **食物回复只有 6 档**：100 / 80 / 64 / 48 / 32 / 16，做一张表即可，烤肉直接回满。
- **掉落表分母固定 32**：`randi_range(0, 31)` 查 32 项表即可，不要浮点权重；掉落 ID `10~13` 原版会崩溃，**不要复现**。
- **M-16 只随机掉落**（无稳定获取方式）；**续关必带 4 发火箭筒**；火把仅第 5 关、屠夫刀仅第 2 关。
- **Cadillac 仅第 3 关**：摄像机位置 `0x7D00` 之前才能呼叫、`0x3000` 之后才能下车；不拿车刷分更多，但受 3:00 时限压迫。
- **宝物分值完全缺失** `[待核对]`，先用「按稀有度递增」的占位分值。

> 来源：[RQ87 shrine 武器页](https://rq87.flyingomelette.com/RQ/CAD/wep.html)。
> 原版共 3 类可拾取物：**近战武器、投掷物、枪械**，另有可破坏的容器与
> 弹药补给。原版未公开伤害数值，下表的「伤害定位」为**相对强弱**描述，
> 已如实标注来源。

## 通用规则

| 规则 | 说明 | 可信度 |
| --- | --- | --- |
| 拾取 | 走到道具上即自动拾取（部分道具需按攻击键） | `[原版实测/文档]` |
| 近战武器 | 装备后按攻击键挥击 | `[原版实测/文档]` |
| 投掷类 | 装备后按攻击键投出，**距离敌人较远时**近战武器也会被投出 | `[原版实测/文档]` |
| 枪械弹药 | 每把枪有固定弹数，打空后**可再拾起当作近战武器或投掷** | `[原版实测/文档]` |
| 弹药补给 | 拾取「ammo」后，**下一次拾起的武器弹药补满** | `[原版实测/文档]` |
| 同时只能持有一件 | 拾取新武器会丢弃当前武器 | `[推定]` |

> **弹药补给的正确用法**（原版文字说明）：把 Uzi 打空 → 捡弹药 →
> 再捡起 Uzi，此时 Uzi 弹药为满。

## 近战武器

| 武器 | 说明 | 强弱定位 | 出处 |
| --- | --- | --- | --- |
| **Knife** 小刀 | 短距离刺击；离敌人远时按攻击会**投掷**小刀 | 弱 | 常见 |
| **Rod** 棍棒 | 砸头用，威力较大；**打中敌人两三次后会断**，剩下的一截当作小刀用 | 强（会损耗） | 常见 |
| **Club** 大棒 | 行为与棍棒类似，但**不会断裂** | 强（耐久） | 常见 |
| **Torch** 火把 | 击中敌人会**使其着火** | 强（附加燃烧） | **仅第 5 关** |
| **B. Knife** 屠夫刀 | 攻击方式与 Club 相同 | 强（耐久） | **仅第 2 关**，需打倒 Boss Butcher 时从其手中打落 |

## 投掷物

| 道具 | 说明 | 强弱定位 | 出处 |
| --- | --- | --- | --- |
| **Stone** 石头 | 拾取后按攻击键投掷；有不同颜色（棕色等） | 弱 | 常见 |
| **Grenade** 手雷 | 可拾取并投掷，**接触敌人或数秒后爆炸**；对付成群敌人极佳 | 强（范围） | 常见 |
| **Dynamite** 炸药 | 可拾取并投掷，投出后**引信点燃**，数秒后爆炸，范围内敌人受伤 | 强（范围，有延迟） | 常见 |
| **Barrel** 油桶 | 可破坏（内含道具），也可**举起投掷**；**举着时不能奔跑或跳跃** | 强（范围） | 场景中大量分布 |

## 枪械

弹药数为**从 ROM 提取的原版数值**，不是估计值。

| 武器 | 弹数 | 说明 | 打空后的用途 | 强弱定位 |
| --- | --- | --- | --- | --- |
| **Gun** 手枪（Revolver） | **6** | **全游戏最弱的枪**；连中 3 发通常能让敌人倒地 | 可拾起投掷 | 弱 |
| **Shotgun** 霰弹枪 | **6** | **爆炸范围宽**，一发可清掉一小群敌人 | 可拾起投掷 | 强（范围） |
| **Rifle** 步枪 | **6** | 射速慢，但单发伤害高 | 可拾起当**棍棒**挥打 | 强（单发） |
| **Uzi** 乌兹冲锋枪 | **48** | 点射式连发，命中数发即可击倒敌人；**对第 3 关 Boss Hogg 极为有效** | 可拾起投掷 | 强（持续输出） |
| **M-16A1** 自动步枪 | **48** | 按住攻击会**散乱扫射**，压制面大；**全游戏最稀有**，只能从被打碎的物件中随机掉落 | 可拾起当**棍棒**挥打 | 强（稀有） |
| **Bazooka** 火箭筒 | **4** | 命中即造成**巨额伤害** | —— | 最强 |

> **注意**：攻略站把乌兹 / M16 描述成「连发」很容易让人以为弹药很少，
> 但原版实际是 **48 发**的弹药池。这一点直接影响武器平衡，
> 复刻时不要按 6 发来实现。

> ROM 地址（初始弹药）：步枪 `0x24D9E`、手枪 `0x24DDE`、乌兹 `0x24E34`、
> M16 `0x24E5E`、霰弹枪 `0x24E84`、火箭筒 `0x24EAA`。`[ROMDATA]`

### 特殊：M-16A1 没有稳定获取方式

据 [faq 页](https://rq87.flyingomelette.com/RQ/CAD/faq.html)：
M-16A1 是**完全随机**从可破坏物件中掉落的。例如第 1 关后半段的雕像里
有时会有，但大多数时候没有。**不存在必定刷出的方法。**

> 复刻时若要保留这一点，应该把 M-16A1 做成关卡配置里的低概率掉落，
> 而不是固定放置。

### 特殊：续关自带火箭筒

任何情况下续关，角色都会自带一把 **4 发火箭筒**（见
[03-controls-and-system.md](./03-controls-and-system.md#续关-continue)）。

## 回复道具（食物）—— 原版回复量

玩家血条 **1 格 = 100 HP**，角色初始 HP 也是 100，

| **Hotdog** 热狗 | **48** | **Coffee** 咖啡 | **16** |
| **Pizza** 披萨 | **48** | **Croissant** 牛角包 | **16** |

## 掉落系统（可直接照搬）

| 项目 | 说明 |
| --- | --- |
| 木桶掉落表 | ROM `0xB64F2` |
| 敌人掉落表 | ROM `0xB6D12` |
| **表结构** | **每个掉落 ID 对应 32 个值，概率分母固定为 32（`N/32`）** |
| 敌人掉落处理 | 代码 `0x24B36` |
| 木桶掉落处理 | 代码 `0x24B48` |
| 枪械弹药掉落判定 | 代码 `0x24B76` |

**示例掉落 ID：**

| ID | 内容（数值 `/32`） |
| --- | --- |
| `01` | 手枪 31、M16 1 |
| `02` | 珍珠 3、项链 3、戒指 3、怀表 3、硬币 15、现金 $1000 3、墨镜 1、手套 1 |
| `05` | 炸药 16、手雷 16 |
| `06` | 乌兹 31、M16 1 |
| `30` | 钻石 31、硬币 1 |
| `31` | 对讲机（呼叫 Cadillac） |
| `62` | 全套武器散布（含**空 5/32**） |
| `68` | 霰弹枪 24、乌兹 7、火箭筒 1 |

> 这套「分母固定 32」的设计非常好实现：用 `RandomNumberGenerator.randi_range(0, 31)`
> 取一个索引，再查 32 项的表即可，不需要浮点权重。
> 完整掉落表见 [08-rom-data-tables.md](./08-rom-data-tables.md#8-掉落表机制)。
>
> ⚠️ **原版 bug**：掉落 ID `10`、`11`、`12`、`13` 会让游戏崩溃。
> 复刻时**不要**复现这个 bug。

## 载具：Cadillac

| 项目 | 说明 | 可信度 |
| --- | --- | --- |
| 获取方式 | 在第 3 关拾取 **Radio**（对讲机）呼叫 | `[原版实测/文档]` |
| 使用范围 | **只能在第 3 关**驾驶 | `[原版实测/文档]` |
| 操作 | 可自由驾驶，撞击碾倒敌人 | `[原版实测/文档]` |
| 耐用性 | 有**独立的 HP**（存档槽 `+0x6C`），Hogg 可以打坏它 | `[ROMDATA]` |
| **呼叫限制** | 只能在摄像机位置 **`0x7D00` 之前**呼叫 | `[ROMDATA]` |
| **下车限制** | 摄像机位置 **`0x3000` 之后**才能下车 | `[ROMDATA]` |
| 对 Boss | Hogg 会持续投掷手雷；只要持续撞他并躲手雷，可以**在不损坏车的情况下击杀他** | `[原版实测/文档]` |

> **也可以不拿对讲机**：第 3 关允许全程步行通过，但关卡会变得很长、
> 敌人极多，且要小心时间耗尽（见
> [faq 页](https://rq87.flyingomelette.com/RQ/CAD/faq.html)）。
> 若以刷分为目的，步行反而更划算。

## 工程实现建议

供复刻参考（与 [README.md](../README.md#物理层) 中的层号对应）：

| 类别 | 物理层 | 说明 |
| --- | --- | --- |
| 场景中可拾取的武器 / 道具 | `pickable` (5) | 玩家用 Area2D 检测重叠自动拾取 |
| 被投出的武器 / 投掷物 | `player_attack` (3) 或独立投射物场景 | 需要区分「玩家持有」与「飞行中」两种状态 |
| 可破坏的桶 / 箱子 | `obstacle` (6) | 受击掉血，破坏时按掉落表生成道具 |
| 载具 | `player` (1) | 作为特殊玩家状态，切换操作目标 |

建议用一份数据表（`Resource` 或 CSV/JSON）描述所有武器，
字段至少包含：`id`、`显示名`、`类型`、`伤害`、`弹数`、`射程`、
`是否可投掷`、`打空后行为`、`掉落权重`。
