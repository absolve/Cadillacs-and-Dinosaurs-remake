## 完整敌人名单（来自 ROM 生成表）

原版 ROM 的刷怪表里有**带名字的敌人 ID**，这比攻略站的口语化称呼准确得多。
完整 ID 表见 [08-rom-data-tables.md](./08-rom-data-tables.md#5-敌人--物件-id-表rom-生成表原始-id)，
下表是可读的汇总：

| 分类 | 敌人名 | 说明 |
| --- | --- | --- |
| 摩托手组 | **Ferris** / **Driver** / **Gneiss** | 同一 ID 下的 3 种子类型 |
| 持刀组 | **Blade** / **Razor** | 近战型占 3 个槽位，投掷型占 1 个 |
| 混混组 | **Punk** / **Thug** | 基础杂兵 |
| 胖子组 | **Hammer T.** / **Crash Game** / **Blk Elmer** / **Wrench T.** | 5 种子类型（其中 Crash Game 出现两次） |
| 猎人 / 枪手组 | **Poacher J** / **Skinner** / **Gutter** | 「猎人」的正式名 |
| 副 Boss | **Lash T.**（Lash Terhune） | 抓取型，**需要 3 个空闲槽位** |
| 副 Boss | **Bludge** | 大块头，会**吐东西**（有独立的 Bludge Spit 精灵库） |
| Boss 换色 | **Walther** | 子类型 0 = Vice，子类型 2 = Walther |
| 剧情 NPC | **Old Man (Dies)** | 被 Morgan 射杀的求救者 |
| 中间 BOSS | **Tyrog** / **Tyrog 2** / **Tyrog 3rd T.** | 多个 ID |
| Boss | **Butcher** / **Hogg** / **Slice** / **Morgan** / **Morgue** / **Slisaur** / **Fessenden 1st / 2nd** | |

> **命名纠正**：攻略站把 `Lash T.` 写成「持钉头锤的混混」，
> ROM 里的正式名是 **Lash T.（Lash Terhune）**，且他是**副 Boss**；
> 「Blanka 山寨版」的正式名是 **Bludge**（攻略站也写成 Bludger）。

### 生成槽位预算

原版对同屏敌人有**槽位预算**，不同敌人占用的槽位数不同：

| 占用槽位 | 敌人 |
| --- | --- |
| **1** | Biker、Bike、Hunter、Fat、Dwarf、持刀投掷型、R Hopper、Zeke、Mack、Shivat、Small Dino |
| **2** | 持雷 / 持炸药的 Dwarf、**Dino Foot（雷龙腿）**、**Bludge** |
| **3** | 持刀近战型、**Lash T.** |

> 复刻时若不做槽位预算，同屏敌人会比原版多得多，
> 手感会明显变难。建议在关卡数据里给每种敌人一个 `slot_cost`，
> 刷怪时累加不超过上限。

### 敌人 HP（ROM 数值）

| 敌人 | HP |
| --- | --- |
| 投掷型杂兵（Blade、扔手雷 / 炸药的混混） | **12** |
| **Zeke**（翼龙）等 | **50** |
| 副 Boss（Lash T.、Bludge 等） | **200**（最高难度档 **500~600**） |

另外 HP 还要加上**难度加成**（0 / 32 / 66 / 100 / 0 / 66 / 132 / 200）。
完整表见 [08-rom-data-tables.md](./08-rom-data-tables.md#4-敌人-hp-分层)。

> **实测小技巧**：把 DIP 开关 **B6 与 B8** 打开，游戏会**显示命中盒**；
> 配合 MAME 调试器读取 `$FFD364` 起的敌人内存区，可以精确测出每个敌人的 HP。

## 恐龙

恐龙在原版中既是敌人也是**场景机制**，需要单独处理：

| 恐龙 | ROM 正式名 | 出现方式 | 机制 |
| --- | --- | --- | --- |
| **Raptor** 迅猛龙 | **R. Hopper**（145×86） | 第 1 关 Boss 战，被 Vice 用锁链拴住并激怒 | 有**撕咬投技**；被打倒后**变回绿色皮肤跑掉**（不死亡）；离屏超过 **480 px** 会自行离开 |
| **Triceratops** 三角龙 | **Mack**（219×73，沉睡 215×66） | 第 2 关开场 | 两只愤怒的三角龙，**可以打死也可以直接跑过去**；离屏后**不会消失，会从反方向回来** |
| **Sleeping T-Rex** 沉睡霸王龙 | **Shivat**（沉睡 273×58 / 愤怒 211×153） | 第 2、5 关 | **中立状态**，敌人会试图叫醒它；被叫醒后成为敌人，必须打倒 |
| **Brontosaurus Leg** 雷龙腿 | **Dino Foot**（109×224） | 第 6 关丛林 | **不可攻击的场景机制**，会不断踩踏，**能踩伤敌人**；**占用 2 个生成槽位** |
| **Background Dinosaur** 背景恐龙 | — | 第 6 关沼泽 | **纯粹背景，不会伤害玩家** |
| **Pterodactyl** 翼龙 | **Zeke**（141×139） | 第 8 关 | 飞行敌人，**HP 50** |
| **Unused Small Dino** 未使用小恐龙 | **Small Dinosaur**（89×35） | 未采用 | 体型很小，有**咬击**动作 |

> **设计提示**：原版明确把恐龙设定为**中立生物**（会同时攻击玩家和敌人）。
> 这是一个很有特色的机制：第 6 关的雷龙腿和第 2 关的 T-Rex 都应该
> 对**双方**造成伤害，而不是只打玩家。

## Boss 一览

| 关卡 | Boss | 特征 | 主要攻击 | 弱点 / 对策 |
| --- | --- | --- | --- | --- |
| 1 | **Vice** | 全游戏最弱的 Boss | 飞踢、**手枪（始终持有）**、快速跳跃走位、**呼叫援兵** | 躲开飞踢，反复用普通连击 |
| 2 | **Butcher** | 双手持刀，能快速跳跃游走 | 两套**冲刺斩**（持刀 / 空手）、**反复屁股坐** | 打倒他会**掉落刀子可捡起使用**；多用冲刺攻击打断 |
| 3 | **Hogg** | 骑摩托车 | **投掷手雷**、**开车冲撞** | 有车时持续撞击；他冲撞时用**跳跃踢**反击；躲开手雷 |
| 4 | **Slice**（Slicer） | 冲刺时留下**一串残影** | **冲刺斩**、回旋镖（单发 / 全屏散射） | 无视杂兵，**任何角色的冲刺攻击**都有效 |
| 5 | **Morgan** | 体型小、速度快 | 开枪、扔手雷、近距离**用乌兹砸人** | **血量很低**，几下发就行 |
| 5 | **Morgue**（Morgan 二阶段） | 变异恐龙 | 近身爪击、**冲刺头槌** | 头槌前会**原地空跑约 1 秒**；捡他掉落的乌兹；把他**压制在角落** |
| 6 | **Tyrog** | 寄生物附身人类后变异，**三段形态** | 形态 1：挥爪 + **胸口裂开飞出刀状物**<br>形态 2（橙）：**吐火球**<br>形态 3：前两者 + **四周喷血** | 形态切换间隙可攻击**寄生物**；用冲刺攻击中远距离打（他会跳来跳去，还有跳跃压杀） |
| 7 | **Slisaur ×2**（2~3 人时 ×3） | Slice 的**变异版**，同款残影 | 冲刺斩、回旋镖 | 把一只压在屏幕一侧；充分利用冲刺攻击 |
| 8 | **Tyrog 2** | 与 Tyrog **蓝色形态**攻击相同但更弱 | 挥爪等 | **只需打一次**，比正体简单 |
| 8 | **Fessenden（第 1 形态）** | 变成**与 Morgue 同型**的变异恐龙 | Morgue 全套攻击，尤其**冲刺头槌** | 同 Morgue 打法 |
| 8 | **Fessenden（第 2 形态，最终 Boss）** | **三头怪** | 近身**爪击**、**连发火球**、**咬住后甩出**的投技 | **抗击倒极强**，打两下就要撤；火球**预兆是某个恐龙头突然抬起** |

## 关于 Boss 复用的设计规律

原版大量复用素材，复刻时可以直接照搬这套「换皮 / 变异」体系，
它同时也是叙事线索：

| 原版 | 复用形式 | 复现于 |
| --- | --- | --- |
| **Vice**（第 1 关 Boss） | **换色**变成 **Walther**，作为普通敌人 | 第 4、5、6、8 关 |
| **Slice**（第 4 关 Boss） | **变异**成 **Slisaur**，且**数量翻倍** | 第 7 关 |
| **Morgue**（第 5 关 Boss） | **同型**成为 **Fessenden 第 1 形态** | 第 8 关 |
| **Tyrog**（第 6 关 Boss） | **弱化版**成为 **Tyrog 2** | 第 8 关 |

> 这套复用的实现建议：把 Boss 做成**同一份数据 + 不同参数**
> （换色 palette、HP 倍率、攻击表子集、数量），而不是各写一套 AI。

## 未使用素材

来源：[未使用素材页](https://rq87.flyingomelette.com/RQ/CAD/unu.html)
（部分由 Tomas Rivero 发现）

| 素材 | 推测用途 |
| --- | --- |
| 开发人员的**漫画式头像**（其中一张是《街霸 II》的 Ryu） | 通关 / 隐藏结局的 Credits 演出 |
| 驾驶关相关素材 | 未完成的驾驶关功能 |
| 驾驶关的**文字提示** | 砸桶时显示文字 |
| **街机摇杆、按键、方向箭头**的图标 | 未完成的「如何游玩」教学序列 |
| 大型敌人的**拾取并投掷物件**动作 | 原本可能是可抓取物件的敌人 |
| **Gnesis 与 Ferris** 的待机动作 | 被裁剪的演出 |
| 同一对人的**下落 / 踢击**动作 | 可能原本用来**踢开桶** |
| **一只小恐龙**（有咬击动作） | 被裁剪的敌人 |

> 这些素材说明**游戏原本存在隐藏结局 / Credits 演出的计划**。
> 玩家社区至今没找到触发方式（尝试过一命通关、无伤通关、高分、
> 击杀全部橙色恐龙等），原版可能存在未被发现的隐藏结局。
> 详见 [faq 页](https://rq87.flyingomelette.com/RQ/CAD/faq.html)。
