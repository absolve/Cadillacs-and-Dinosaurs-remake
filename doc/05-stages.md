## 刷怪记录结构（16 字节）

原版的每一批刷怪记录都是定长 **16 字节**，字段含义如下。
**这个结构可以直接照搬成复刻的关卡数据格式**：

| 字段 | 长度 | 含义 |
| --- | --- | --- |
| `TS` | 2 | 触发 / 延迟帧（若本条是锁，则作为帧延迟） |
| `B1` | 1 | 高位 = **人数标记**（**0 = 总是生成**，4 = 2 人，6 = 3 人）；低位 = 物件类型（**0 敌人、1 其他、2 ？、3 木桶/宝物**） |
| `OI` | 2 | 物件 / 敌人 ID（对照 [08 的 ID 表](./08-rom-data-tables.md#5-敌人--物件-id-表rom-生成表原始-id)） |
| `PX` | 2 | X 坐标 |
| `PY` | 2 | Y 坐标 |
| `AI` | 1 | 动作 / 姿态 |
| `SI` | 1 | 子类型 |
| `DL` | 2 | 恐龙数量上限 |
| `DI` | 1 | 掉落 ID（查掉落表） |
| `IL` | 1 | 智能 / 攻击性 |

**「人数标记」直接就实现了「多人时敌人更多」** —— 不需要额外的难度逻辑，
只要在读取刷怪记录时按当前人数过滤即可。

## 原版没有隐藏关 / 奖励关

在所有可达资料中**没有发现奖励关（bonus stage）**。原版唯一的「特殊段落」是：

1. 第 3 关的**驾驶段**；
2. 第 7 关的**纵向下降段**（984×14320）；
3. 作弊用的**关卡选择**（`$FF84D9` 写 0~7）。

## 第 1 关：City in the Sea

**流程分段：**

1. **屋顶（剧情开场）**：Vice 派手下「教训」你，角色会**自动发动必杀技**
   秒杀这批人，之后关卡正式开始。
   - 向右推进，出现游戏中最弱的敌人（如 **Ferris**）。
   - 右上角的桶可以砸开拿道具（通常是加分道具）。
   - 清光敌人后进入楼内。
2. **楼内**：更多弱敌，并**首次出现**投刀敌人和**冲锋胖子**（伤害很高）。
   - 场上有几把枪可用（霰弹枪或乌兹），能快速清场。
   - 清光后角色**自动跳出窗户**。
3. **街道**：落地后一个胖子跳下来，另一个敌人撞破门而入。
   - 清光后向右走到 Vice 面前。Vice 用锁链拴着一只恐龙，并把它激怒来攻击你。
4. **Boss 战**：
   - **先打迅猛龙**：它的撕咬投技很烦。打倒后它会**变回绿色皮肤并跑出画面**。
   - **Vice**：会飞踢、**始终持有手枪**、快速跳跃移动、还会**叫援兵**。
     只要躲开飞踢，用普通连击反复打就能很快解决。
   - Vice 是**全游戏最简单的 Boss**，之后会以**不同配色**作为普通敌人登场。

## 第 2 关：The Swamp Forest

1. 从 Cadillac 下车后，出现两只**愤怒的三角龙**（打死或直接跑过去）。
2. 遇到一只**沉睡的霸王龙（T-Rex）**，敌人会试图把它叫醒；
   在它们成功之前解决掉，否则必须与醒来的 T-Rex 战斗。
3. 向右跳下进入**泥沼**，出现若干猎人（AI 很笨，好打）。
4. 跑出沼泽后遭遇更多敌人，其中包括**持钉头锤的 Lash T.**，
   他的武器攻击距离远，要注意保持距离。
5. 天色由昼转夜，路上出现大量恐龙尸体，说明 Butcher 就在附近。
   下方有普通小兵，附近有若干可砸开的桶，每个桶里都有道具。
6. **Boss 战 —— Butcher**：
   - 登场时正在切割恐龙尸体。**双手各持一把刀**，
     把他打倒后刀会掉落，**玩家可以捡起来用**。
   - 与 Vice 一样能快速跳跃游走。
   - 有两套冲刺斩（持刀 / 空手），伤害都很高。
   - 会**连续使用屁股坐（butt drop）**，不打断他会一直坐。
   - 会不断有小兵加入，主要威胁是**被围殴**。
   - 对策：多用冲刺攻击把他打倒。

## 第 3 关：Hell Road（驾驶关）

1. 舞台是**死亡沙漠**，开场是一批较弱的混混。
2. **关键道具**：被打倒的敌人有时会掉落一个**灰色对讲机盒**，
   拾取后**呼叫来 Cadillac**。
3. **两条通关路线**：
   - **不拿车**：能靠击杀全部敌人拿到**多得多的分数**，
     但必须打得快，否则**时间耗尽**。
   - **拿车**：一路撞过去，轻松但要放弃大量分数。
4. **Boss 战 —— Hogg**（骑摩托车）：
   - 有车时：**持续撞他**即可；Hogg 会不断扔手雷，
     Cadillac 能承受多次攻击，被打够次数后会被迫下车。
   - 无车时：Hogg 会**开车撞你**并同时扔手雷，还会有其他敌人加入，
     但这些敌人常常掉落**乌兹**，可以拿来用。
   - **技巧**：当 Hogg 冲撞过来时用**跳跃踢**，可以打到他而自己不吃伤害。
   - 只要躲开手雷并持续撞击，可以**在车不被打坏的情况下**击败 Hogg。

## 第 4 关：Jack's Garage

1. **过场**：Hogg 被打败后，众人意识到修车厂正被袭击。
   关卡开场用 Cadillac 撞开障碍物，其中一人 **Slice** 逃走，
   留下「修车厂现在归我了」后跳走。
2. 厂外：若干较弱敌人和几个桶。
3. **厂内**：出现 **Walther** —— Vice 的**换色版本**，
   攻击方式相同但更弱。这一区**道具很多**，
   被破坏的桶里藏着各种枪，务必捡走。
4. **摩托车手（bikers）**：很容易被打下车，但不注意会被撞倒。
5. 深处有一个**胖子敌人成群出现**的区域，全灭后**通常会掉乌兹**，
   用它可以轻松应付打 Boss 前的那一段。
6. Boss 前有若干弱混混，随后遇到 **Slice**。
7. **Boss 战 —— Slice**：
   - 移动极快，冲刺时**身后拖出一串残影**。
   - 主要攻击是**冲刺斩**；也会投掷回旋镖，
     有**单发**和**全屏散射**两种版本。
   - 会不断有小兵加入，但建议**无视小兵专心打 Boss**。
   - **任何角色的冲刺攻击**对他都很有效。

## 第 5 关：Village of Flame

1. 村外：常见混混 + 大量游荡的恐龙，**还有另一只沉睡的 T-Rex**
   （阻止敌人叫醒它，叫醒了就得打）。
2. 进入山中：**落石**（能砸到敌人也能砸到玩家），
   砸开桶可以获得不错的武器。
   首次出现**「布兰卡山寨版」Bludge**（Bludger），血量很高但不难打。
3. 更多混混，其中 **Walther 再次登场**（这里更弱）。
   之后有一辆**装满桶的推车**，每个桶都有道具，**能拿到乌兹**。
4. 进入村庄：常见敌人，其中包括一名持钉头锤者。
   找到发出求救信号的人，但他被 Boss **Morgan** 用机枪杀死。
5. **Boss 战 —— Morgan**：
   - 移动很快，会**开枪**、**扔手雷**，
     玩家靠太近时**用乌兹砸你**。
   - 体型小、速度快，比较难打中，但**血量很低**，几下就能打倒。
6. **Boss 二阶段 —— Morgue**：
   - Morgan 被打倒后会**重新站起并变身为变异恐龙 Morgue**，强度大幅提升。
   - 开打时**立刻去捡 Boss 掉落的乌兹**，能立刻打出大量伤害。
   - 近身会用爪击；**最常用的攻击是冲刺头槌**。
   - **预兆**：使用头槌前他会**原地空跑约 1 秒**，看到就要提防。
   - 会有大量小兵加入；建议把 Morgue **压制在屏幕四角之一**。

## 第 6 关：Jungle and Mine

1. 矿坑入口外：若干混混，其中有**持刀者**。
2. 矿坑内：常见混混 + **Walther 又一次登场**。
   砸桶拿道具。矿坑末段有一个**持钉头锤者 + 若干胖子**。
3. 抵达**丛林**：很快看到**雷龙脚印**，
   接着出现**巨大的恐龙腿不断踩踏**。
   - 这只脚**能踩伤敌人**，所以正确做法是**保持移动让敌人被踩死**。
   - 之后还有一段同样的恐龙腿区域。
4. 又一段很短的沼泽：**背景里的恐龙不会伤害玩家**，
   只需对付猎人、变异体和胖子敌人。
5. 出沼泽后打倒一只 **Ferris**，向右会遇到**三个人和一个箱子**。
   Boss 从箱子里跳出，**附身在其中一人脸上**并变异。
6. **Boss 战 —— Tyrog（三段形态）**：
   | 形态 | 颜色 | 攻击 |
   | --- | --- | --- |
   | 第 1 形态 | — | 挥爪；**胸口裂开伸出一堆刀状物**刺击 |
   | 第 2 形态 | 橙色 | 取消胸口攻击，改为**吐火球**；仍有挥爪 |
   | 第 3 形态 | — | 保留前两阶段攻击，新增**向四周喷血**（能打到玩家） |
   - **形态切换间隙**：寄生物离开宿主去附身下一个敌人时，
     可以趁机攻击寄生物。
   - 第 3 形态时会跳来跳去，还有**跳跃身体压杀**；
     用**冲刺攻击**在中远距离打他比较安全。
   - 场面小兵很多，建议优先速杀 Tyrog。
   - 击败第 3 形态即彻底摧毁寄生物。

## 第 7 关：The Vault

1. 开场在**桥上**，大量敌人，其中有几名**摩托车手**
   （可以直接打掉也可以躲开，他们不会久留）。
2. 过桥后有几个桶，砸开可得 **火箭筒**，对付成群敌人极有效。
3. 进入**金库**：敌人很多但大多较弱，注意**冲锋胖子**。
4. 之后是与数个大型敌人交战的区域。全部击败后角色**自动跳上电梯**并下降：
   - 下降过程中敌人会不断跳下来；
   - 电梯有时会**停下**，让更多敌人跑上来。
5. 最终停在**一道门前**，周围散布着较弱敌人；
   清完敌人后**攻击大门将其破坏**才能继续。
6. **图书馆**：常见敌人，其中有几个 **Bludger**。
   这一区会有**桶从画面外滚来**，最好**打碎它们拿道具**。
7. 出图书馆进入隧道：**冲锋胖子** + 较弱混混。
8. **电脑室**：Dr. Fessenden 通过屏幕现身，嘲讽玩家后派出自己的造物。
9. **Boss 战 —— Slisaur**：
   - 第 4 关 Boss Slice 的**变异版**，保留**残影移动**和**回旋镖**攻击，
     也保留冲刺斩。
   - **数量**：单人 **2 只**；2~3 人游玩时 **3 只**。
   - 因此需要不断走位；建议把一只**压制在屏幕一侧**，
     并充分使用角色的**冲刺攻击**。

## 第 8 关：Deep Deep Down（最终关）

1. **Fessenden 的生物实验室**：人类与怪物敌人轮番攻击，
   部分关着怪物的**培养舱会破裂**，逃出的生物立刻攻击你。
2. 中途要再次面对 Tyrog，这次叫 **「Tyrog 2」**：
   - 攻击方式与原版**蓝色形态**相同，但**更弱**，且**只需打一次**。
3. 清完实验室后发现**下水道井盖**，跳下去。
   这一段可以在**陆地或水中**移动：
   - 建议**走水里**，墙壁喷出的**火焰喷射器**打不到你；
   - 火焰**能伤害敌人**，可以把敌人引到火里；
   - 火焰喷射器本身**可以被打掉**。
   - 敌人包括**冲锋胖子**和**持步枪者**。
4. 掉入**洞窟**：常见敌人，这里能拿到**乌兹**。
   一路向右，经过几个斜坡：
   - 注意**掉落的桶**，打碎可拿道具；
   - 其中一段斜坡有**翼龙**（通常只能被跳跃攻击打到，几下就死）。
5. 地面变平后是**强力敌人**：几名持钉头锤者 + **第 1 关 Boss 的弱化版（Walther）**。
   最后一波是一群**持步枪者**。击败后角色**自动向右走**。
6. **最终 Boss 战 —— Fessenden**：
   - **第 1 形态**：变身成变异恐龙，**与第 5 关 Boss Morgue 同型**，
     拥有 Morgue 的全部攻击，尤其爱用**冲刺头槌**。
   - **第 2 形态（真正的最终 Boss）**：**三头怪**。
     - 主要近身手段是**爪击**。
     - **抗击倒能力极强**：普通连击或冲刺攻击常常**打不倒他**，
       所以要**打两下就撤**，不能贪刀。
     - 会**连发火球**，是他伤害最高的招式之一；
       **预兆是某一个恐龙头突然抬起**，看到就立刻跑。
     - 还有**投技**：其中一个头咬住你后把你甩出去。
   - 这一区几乎没有杂兵（偶尔有持刀者跑来扔刀就跑），可以专心打 Boss。

## 关卡设计要点（供复刻参考）

从上面的流程可以提炼出原版的关卡结构套路，复刻时建议照搬：

| 结构元素 | 说明 | 出现关卡 |
| --- | --- | --- |
| 剧情开场 | 关卡开始时用自动演出的招式清场或过场 | 1、4 |
| 分段推进 | 每关分 3~5 个「清光敌人才能前进」的小段 | 全部 |
| 可砸开的桶 | 每个桶必出道具，是主要的武器补给来源 | 全部 |
| 脚本化障碍 | 落石、滚桶、恐龙腿、火焰喷射器 | 5、6、7、8 |
| 场景交互 | 电梯、大门（需打碎）、水面（躲避火焰） | 7、8 |
| 载具 | Cadillac 驾驶段落 | 3、4 |
| 可唤醒的恐龙 | 沉睡 T-Rex，被叫醒后变成额外威胁 | 2、5 |
| 中 Boss / 多阶段 Boss | Morgan→Morgue；Tyrog 三段；Fessenden 两形态 | 5、6、8 |
| 旧 Boss 复用 | Walther = Vice 换色；Slisaur = Slice 变异 | 4、5、6、7、8 |
