# 开发计划（第 1 关阶段）

## 结论（TL;DR）

- **本阶段目标：把第 1 关（City in the Sea）从选人到打倒 Vice 完整跑通**，四人可选、单人优先，多人同屏放本阶段末尾或下一阶段。
- **实现顺序照搬 [07 的建议](./07-dev-reference.md#七建议的实现顺序)**，按依赖关系切成 7 个里程碑（M0~M6）：工程骨架 → 核心战斗 → 力量系统 → 移动扩展 + 抓取 → 必杀技 → 敌人 + 刷怪 + 前两段 → 演出 + Vice + 收尾。
- **力量（暴击）系统在 M2 就做**，它影响所有伤害计算，放后面会返工。
- **缺数据的部分全部走 `[推定]` 占位**（帧数、移速、敌人伤害、第 1 关时限等），占位值集中放在一张表里，方便日后实测替换。
- **不含原版素材**（版权约束，见 [doc/README](./README.md#版权)）：美术 / 音乐用占位资源，精灵尺寸与判定盒按 [08 §13](./08-rom-data-tables.md#13-精灵尺寸表用于设定判定盒与碰撞体) 搭建。

## 阶段范围

### 本阶段做（In Scope）

| 范围 | 内容 |
| --- | --- |
| 流程 | 开机标题（占位）→ 选人（4 角色）→ 第 1 关 → 打倒 Vice → 过关结算（占位） |
| 角色 | 四人全套招式（[02 招式表](./02-characters.md#各角色专属招式)）+ 数值差异 + 力量（暴击）系统 |
| 战斗 | 连击 / 受击 / 倒地 / 抓取 / 投技 / 冲刺 / 飞踢 / 追踪踢 / 下上攻击 / 必杀技 |
| 敌人 | 第 1 关名单：Ferris、投刀者（Blade）、冲锋胖子（Fatty）、迅猛龙（R-Hopper）、Boss **Vice** |
| 关卡 | 第 1 关三段：屋顶 → 楼内 → 街道（分段锁屏 + 刷怪记录驱动） |
| 演出 | 段内脚本事件：开场自动必杀清场、自动跳窗、R-Hopper 拴链激怒 / 打倒变绿逃走（机制见 [05 §演出](./05-stages.md#演出与剧情过场的控制方式)） |
| 道具 | 桶（必出道具）、霰弹枪 / 乌兹、食物回复、掉落表（N/32） |
| 系统 | HUD（血条 1 格 = 100 HP、命数、计时器、分数占位）、暂停 |

### 本阶段不做（Out of Scope，留到后续阶段）

- 第 2~8 关与驾驶段、纵向卷轴（第 2 关 B / 第 5 关 / 第 7 关 B）；
- 关卡间对话过场（`CutscenePlayer` 框架可先留接口，本阶段只做段内演出）；
- 续关界面完整演出（可先做「续关回到段首」的简化版）、加命 / 排行榜；
- 开场 / 结局动画、区域差异（美欧 / 日版分支）；
- 3 人同屏（P2 / P3 输入通路留好，联调放最后，可顺延到下一阶段）。

## 里程碑

### M0 工程骨架

- [ ] Godot 4 工程结构落地（目录见下文「目录结构」），空场景可运行
- [ ] 输入映射：`p1_*` 前缀全套（攻击 / 跳跃 / 八向 / 双击奔跑判定），`InputRouter` 单例抽象「第 N 位玩家」
- [ ] 数据表 Resource 骨架：`character_stats` / `move_data` / `enemy_stats` / `weapon_data` / `stage_data`（字段清单见 [07 §数据表](./07-dev-reference.md#数据表)）
- [ ] Y 排序测试场景（基准点 = 脚底）、`Camera2D` 跟随最前玩家 + 关卡边界夹取 + 段落锁屏原型
- [ ] `AreaData` 资源（`size` / `walk_band(y_min,y_max)` / `vertical_scroll`）+ 统一的 `clamp_to_area()`：玩家 X 夹在视野矩形内、Y 夹在可行走带内（四层边界机制见 [05 §玩家为什么跑不出地图](./05-stages.md#玩家为什么跑不出地图边界与锁屏机制)）
- [ ] 调试用命中盒显示开关（对应原版 DIP B6 + B8）

**验收**：Jack 在灰色测试房间里八向移动，遮挡正确，摄像机锁屏推进。

### M1 核心战斗（打木桩）

- [ ] 状态机：`IDLE / WALK / ATTACK / HIT / DOWN / RISE`（完整清单见 [07 §状态机](./07-dev-reference.md#状态机)）
- [ ] 三段连击（可取消衔接）、受击硬直、倒地 / 起身（起身无敌）
- [ ] Hitbox + 自增 `hit_id`（同一次挥击对同一目标只结算一次）
- [ ] 敌人被击倒后 **60 帧眩晕免疫**
- [ ] 击倒类攻击**随机概率眩晕**（眩晕敌人站立发呆 = 送打窗口，眩晕贯穿起身动画）；击倒时弹**拟声标签「カタ」**、眩晕头顶标签（机制见 [03 §受击](./03-controls-and-system.md#受击硬直眩晕与无敌)）
- [ ] 伤害计算入口统一走 `基础伤害 × 力量/32`（力量值本里程碑先固定 32）

**验收**：连续攻击木桩敌人，连击取消、击倒、起身无敌行为与 [07 §帧数](./07-dev-reference.md#三动作帧数) 占位表一致。

### M2 力量（暴击）系统

- [ ] 每角色存力量值（基准 32）；**被击中时重掷**：按「已损失 HP 比例」加权，从当前难度块查表（块内容见 [08 §2](./08-rom-data-tables.md#2-力量power--强度-系统--复刻时最容易漏掉的机制)）
- [ ] 伤害缩放生效（36/42/48/64 → ×1.125 ~ ×2.00）；不受伤不衰减
- [ ] 调试 HUD 显示当前力量值（参考改版 PowerIndicator 的做法）

**验收**：满血连击伤害 = 表值（Jack 68），故意挨打到残血后伤害明显上升。

### M3 移动扩展 + 抓取 / 投技

- [ ] 奔跑（双击同方向，窗口 ~200 ms 可调）+ 冲刺攻击（各角色动作不同）
- [ ] 跳跃 / 飞踢 / 追踪踢（空中 ↘ + 攻击）/ 下上攻击（`↓ ↑` 依次输入 + 输入缓冲）
- [ ] 抓取 / 被抓 / 抓取连打（各角色段数不同）/ 投技；Mess 双投技（GRAND SLAM / SUPLEX）与「跑→跳→攻」三段派生
- [ ] Hannah 专属：投掷距离更远（倍率 `[推定]` 先给 1.5，实测后改）

**验收**：[02 招式表](./02-characters.md#各角色专属招式)四名角色全部招式可出、行为正确。

### M4 必杀技

- [ ] 攻击 + 跳跃同按（4 帧容差）；**两段伤害**（自耗 10 + 4 = 14，命中才扣）；命中后 60 帧无敌
- [ ] 眩晕规则：Hannah / Mustapha / Mess 稳定眩晕，Jack 随机概率
- [ ] 起手无敌（`[推定]` 8 帧）

**验收**：连按必杀约 7 次后自杀（100 / 14 ≈ 7），与原版「必杀可连续强攻」的手感一致；受击敌人按角色正确进入眩晕。

### M5 敌人 + 刷怪 + 第 1 关前两段（屋顶 / 楼内）

- [ ] 敌人基类 + 笨 AI（成排走近、攻击欲望低，**不要写聪明**）
- [ ] 三种杂兵：Ferris（最弱）、投刀者（中距离投刀）、冲锋胖子（冲锋撞击、高伤害）
  - HP：投刀者用已知值 **12**；Ferris / 胖子 `[推定]` 占位（见缺口表）
- [ ] 刷怪记录 16 字节结构落地（含人数标记 0/4/6、槽位预算：杂兵 1 槽）
- [ ] 第 1 关第 1 组参数照搬：背景 `level1A`、屏幕区间 920→1120、Y 区间 147/100、默认 11 / 最大 40
- [ ] 第 1 关三段区域数据照搬：`level1A` 2268×300（Y 带 147/100）、`level1B` 1528×224（79/16）、`level1C` 1560×224（63/16）；**6 个 `lock` 组**用「已生成敌人数」计数器解锁（对应原版 `$FFB358`）
- [ ] 桶（必出道具）+ 掉落表（分母 32 取模，掉落 ID 10~13 崩溃不复现）+ 弹药（霰弹枪 6 / 乌兹 48）+ 食物回复表
- [ ] HUD：血条（1 格 = 100 HP，22 格上限）、命数、计时器、分数（占位分值）
- [ ] 死亡 / 命数耗尽 → 简化续关（回段首，`[推定]`）

**验收**：屋顶 + 楼内两段按 [05 第 1 关流程](./05-stages.md#第-1-关city-in-the-sea)可玩：清完锁屏解锁、桶出道具、枪可用可打空、胖子冲锋有威胁。

### M6 演出 + Boss Vice + 收尾

- [ ] 段内演出（复用刷怪系统：剧情专用对象 + `AI` 姿态 + 触发区间，玩家进 `CUTSCENE` 状态）：
  - 开场 Vice 派手下 → 玩家角色**自动必杀清场**；
  - 楼内清完**自动跳窗**进街道段；
  - 街道段 Vice **拴链激怒迅猛龙**；
  - R-Hopper：先打它、撕咬投技有威胁、**打倒后变绿逃出画面**；
- [ ] Boss Vice：82×105 精灵尺寸；飞踢、**始终持枪**、快速跳跃移动、**叫援兵**（Boss 援兵组 = 4 组）
  - HP `[推定]` 占位（副 Boss 200 的量级参考）；行为按 [05 §Boss 战](./05-stages.md#第-1-关city-in-the-sea)
  - **数据留口**：换色复用（Vice → Walther 调色板索引），供后续关卡直接复用
- [ ] 打倒 Vice → 过关结算（占位：分数 / 剩余命数展示）→「第 1 关完成」占位画面
- [ ] 全局流程串接：标题 → 选人 → 关卡 → 结算（`GameFlow` 单例）
- [ ] （可选，时间允许）P2 加入：双人同屏验证 `InputRouter` 通路

**验收（本阶段 DoD）**：
1. 四角色均可选，单人用任一角色从选人打通第 1 关到 Vice 倒地；
2. 全程无脚本报错，段内演出完整播放且可控可跳过（按 START）；
3. 力量系统生效（残血伤害上升可观察）；
4. 手感抽查：对照原版录像逐段检查推进节奏（敌人密度、锁屏时机、Boss 战长度）。

## 风险与依赖

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 占位数值与原版手感偏差大 | 返工 | 占位集中管理；里程碑验收都以「对照原版录像」结束 |
| 演出系统过度设计 | 拖慢 M6 | 只做段内事件（刷怪记录扩展），`CutscenePlayer` 本阶段只留接口 |
| 占位美术 / 音频与最终资源差异 | 后期替换成本 | 精灵尺寸按 [08 §13](./08-rom-data-tables.md#13-精灵尺寸表用于设定判定盒与碰撞体) 定判定盒，替换资源不改逻辑 |
| 力量重掷公式无原版依据 | 手感争议 | 已按社区共识实现「残血加权」，公式参数做成 Resource 可调（见 [02 §力量](./02-characters.md#隐藏机制力量power)） |
