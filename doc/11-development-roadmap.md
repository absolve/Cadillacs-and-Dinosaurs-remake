# 总体开发路线图（第 1 关 → 全部 8 关）

## 结论（TL;DR）

- **当前目标不变：完整跑通第 1 关**（选人到打倒 Vice），细化里程碑见 [09-development-plan.md](./09-development-plan.md)，本文不重复。
- **改版口径（2026-11-06 拍板）：4 人同屏**（原版 ROM 为 3 人）——输入映射 / HUD 4 卡片 / `count_flag=8` 新档已落地，联调与选人 4 槽排入 Phase 2/3（doc/09 §改版拍板）。
- **后续目标：全部 8 关**，按依赖关系切三个阶段——Phase 2（第 2~4 关，补纵向卷轴与驾驶段）、Phase 3（第 5~8 关，多阶段 Boss 与终局流程）、贯穿线（`[推定]` 实测替换、演出框架、多人、音频）。
- 每个 Phase 都以「第 N 关从选人可打通到 Boss 倒地 + 无头断言全绿」为验收门槛；数值/机制数据在 doc/05/08/10 已基本备齐，缺口集中在帧数与手感参数。

## Phase 1：复刻第 1 关（当前，进行中）

按 [09-development-plan.md](./09-development-plan.md) 的 M0~M6 执行，此处只列剩余工作：

1. **M0/M1 收尾**：双击奔跑 + `InputRouter`；击倒随机眩晕 +「カタ」标签；伤害入口统一。（`AreaData` / 段落锁屏已随房间链落地）
2. **M3**：奔跑/冲刺攻击、抓取/投技（含 Mess 双投技、Hannah 远投）、追踪踢、下上攻击；**补 Mustapha、Mess 两个角色**（stats + 场景 + 招式）。
3. **M4**：必杀技（攻击+跳跃同按、两段伤害、自耗 14、命中后 60 帧无敌、按角色眩晕规则）。
4. **M5**：Fatty、R-Hopper、Vice 数值与场景；16 字节刷怪记录 + 槽位预算；第 1 关三段 `AreaData`（1A 2268×300 / 1B 1528×224 / 1C 1560×224，Y 带照 doc/05）；**关卡加载按「房间 = 数据驱动锁屏段」策略**（`StageDirector` + 视野 ±1 房间流式加载，详见 09 §关卡加载策略）；桶 + 掉落表 + 枪械弹药 + HUD + 简化续关。
5. **M6**：段内演出（开场自动必杀、自动跳窗、R-Hopper 拴链/变绿逃走）、Boss Vice、`GameFlow` 串接标题→选人→关卡→结算。

**DoD**：任一角色单人从选人打通第 1 关到 Vice 倒地；断言全绿；力量系统可观察。

## 贯穿线（不排期、每个里程碑都推进）

1. **`[推定] → [ROMDATA]` 实测替换**：帧数、移速/跳高、敌人 HP/伤害、力量重掷加权公式、眩晕帧数——用 MAME 调试器 / arcade-sprite-viewer 命中盒逐项核对，只改 `script/data/` 资源（占位纪律见 09）。
2. **数据转写**：doc/08/10 已提取的力量表、伤害表、317 条判定盒、刷怪参数逐关转成 `.tres`，优先做成生成脚本而非手填。
3. **音频**：`sound/` 目前为空壳；每关落地时补 BGM/音效占位，Phase 3 统一替换。
4. **回归断言**：每加一个机制补一组无头断言（沿用 `object_states_test.gd` 模式），保持「断言全绿」这一硬门槛。
5. **本地化**：骨架已建（2026-11-06）——`lang/translations.csv`（keys / en / zh_CN，10 条种子文案），
   工程已注册双语言 `.translation`；UI 文案一律 `tr("KEY")`，切换入口 `Game.set_locale()`；
   后续各里程碑把散写死的英文键补进 CSV。
