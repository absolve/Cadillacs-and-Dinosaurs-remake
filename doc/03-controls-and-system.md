# 操作与系统规则

## 结论（TL;DR）

- **原版只有 8 向摇杆 + 2 键**，所有招式都是这两个键的组合；奔跑建议做成「双击同方向」，窗口做成可调参数（约 200 ms）。
- **必须实现的三条战斗规则**：必杀技扣自身 14 HP（命中才扣）+ 之后 60 帧无敌；敌人倒地后 60 帧眩晕免疫（防无限连晕）；Boss 倒地**无**无敌帧（可无限连击锁定，保留与否是设计选择，但要知情）。
- **角色伤害会随战斗变强**：连击伤害（力量 = 32 时）Jack 68 / Hannah 67 / Mustapha 65 / Mess 78；力量（Power）**每次被击中重掷**，残血越容易掷出高值（36/42/48，最高难度可到 64），不受伤则保持；伤害按 `基础 × 力量/32` 缩放、最高翻倍（见 [08 §2](./08-rom-data-tables.md#2-力量power--强度-系统--复刻时最容易漏掉的机制)）。
- **难度共 8 档**，敌人 HP 加成 `0/32/66/100/0/66/132/200`；「多人时敌人更多」由刷怪记录里的人数标记驱动，**不是难度逻辑**。
- **玩家跑不出地图 = 四层机制**：摄像机被关卡尺寸夹取、玩家 X 夹在当前视野内、每个「关卡 × 区域」有一条**可行走 Y 带**（ROM 查表）、`lock` 段锁屏时**视野右缘即是墙**（`$FFB358` 计数解锁）。
- **已知缺口** `[待核对]`：加命阈值、宝物分值、动作帧数、移速 / 跳高 / 攻击距离、输入窗口，均需实测补齐。

> 来源：[RQ87 shrine 角色页](https://rq87.flyingomelette.com/RQ/CAD/char.html)、
> [game 页](https://rq87.flyingomelette.com/RQ/CAD/game.html)、
> [faq 页](https://rq87.flyingomelette.com/RQ/CAD/faq.html)。

## 街机原始操作

原版只有 **8 向摇杆 + 2 个按键**，这是理解全部招式的前提：

| 输入 | 说明 |
| --- | --- |
| 摇杆 | 8 方向移动，双按同方向 → **奔跑** |
| 攻击键（Attack） | 近身连打即 COMBO；拾取/投掷武器 |
| 跳跃键（Jump） | 跳跃；与攻击键同按 → **必杀技** |

工程内的键位映射见仓库根目录 [README.md](../README.md#操作映射)。

## 奔跑的触发方式

原版是**推杆两次同方向**进入奔跑（dash）。复刻时有两条常见路线：

1. **忠实原版**：双击同方向进入奔跑，持续按住方向键维持。
2. **现代化**：单独一个「奔跑」键（可选）。

建议按方案 1 实现，把双击间隔窗口做成可调参数（`[推定]` 建议 200 ms 内）。

## 移动边界（为什么跑不出地图）

原版没有「空气墙」物件，玩家被限制住是**四层机制叠加**：

| 层 | 规则 | 可信度 |
| --- | --- | --- |
| 摄像机夹取 | 摄像机 X 被关卡尺寸限制在 `[0, 区域宽度 − 384]`（视野 384×224） | `[ROMDATA]` + `[推定]` |
| 视野夹取玩家 X | 玩家 X 每帧夹在**当前视野矩形**内，左右边距具体值 `[待核对]` | `[推定]` |
| **可行走 Y 带** | 每个「关卡 × 区域」有一条 Y 上下限，ROM 用 `关卡ID×4 + 区域ID` 查表；越界后由落地例程重新贴地。第 1 关：A 147/100、B 79/16、C 63/16 | `[ROMDATA]` |
| **锁屏** | 进入 `lock` 敌人组后摄像机冻结，**视野右缘即是墙**；`$FFB358`（已生成敌人数）满足条件才解锁 | `[ROMDATA]` |

> 出屏判定用的窗口是**相对摄像机 X ∈ `[−64, +448]`**（屏宽 384，两侧各 64 px 容差）；
> 少数从画面外进来的实体（第 6 关恐龙脚）带 `noLevelLimits` 豁免标记。
> 完整推导、ROM 例程地址与 Godot 实现建议见
> [05 §玩家为什么跑不出地图](./05-stages.md#玩家为什么跑不出地图边界与锁屏机制)。

## 抓取（Grab）规则

- 走到敌人身边**贴住**即可抓住，不需要额外按键。
- 抓住后敌人会短暂挣扎，上方会出现**按键提示图标**，提示玩家连打攻击键。
- 抓住状态下：
  - 连打攻击 → 抓取连打，打完后敌人倒地。
  - 按住左/右 + 攻击 → 投技（正向或反向）。

> **敌人可抓性**：不是所有敌人都能被抓。`[推定]` 体积大的敌人（fat 类）
> 与部分 Boss 无法抓取，需要实测确认。详细名单见
> [06-enemies-and-bosses.md](./06-enemies-and-bosses.md)。

## 受击、硬直、眩晕与无敌

原版的这套规则对战斗手感影响极大，**复刻时必须实现**：

| 规则 | 值 | 来源 |
| --- | --- | --- |
| 必杀技自身消耗 | 第 1 段 10 + 第 2 段 4 = **14** | `[MOD引原版]` |
| 必杀技后无敌 | **60 帧**（约 1 秒） | `[MOD引原版]` |
| **击倒后的眩晕免疫窗口** | 敌人被击倒后有 **60 帧（1 秒）**，期间**任何攻击都无法使其眩晕** | `[MOD引原版]` |
| 普通击倒造成眩晕的概率 | **随机概率** —— 改版作者原话：*"random if the enemy is going to become dizzy or not"*，眩晕不是必出 | `[MOD引原版]` |
| 必杀技造成眩晕的概率 | Hannah / Mustapha / Mess **稳定触发**；**Jack 是随机概率**（与普通击倒相同） | `[MOD引原版]` |
| 眩晕的视觉指示 | 敌人头顶出现**标签贴图**（ROM 标签系统含 `Zzzz`、`Ka Ta`，见 [08 §15](./08-rom-data-tables.md#15-掉血--硬直--无敌规则)；眩晕具体用哪张 `[推定]` 复用 `Zzzz`） | `[ROMDATA]`／`[推定]` |
| **起身眩晕** | 被击晕的敌人**眩晕贯穿倒地与起身动画**（起身播完才恢复，期间站立发呆 = 送打窗口）；起身 60 帧免疫窗过后可被再次随机击晕 | `[MOD引原版]` + 玩家实测 |
| **Boss 被击倒后的无敌** | **原版没有** —— 因此可以**无限连击锁定 Boss** | `[MOD引原版]` |
| 可被锁定的 Boss | Butcher、Slice、Morgan、Tyrog、Fessenden 第 1 形态（**Slisaur 刻意除外**） | `[MOD引原版]` |
| 敌人默认怒气值 | **0**（改版把它强制改成 FF 来提升难度） | `[MOD引原版]` |
| 「无敌」标记 | 玩家存档槽 `+0x00`：**1 = 正常，2 = 无敌**；被击倒、投掷敌人、使用必杀等都会置位 | `[ROMDATA]` |

> **关于连击锁定**：原版 Boss 被击倒后**没有无敌时间**，
> 所以高手可以用连击把 Boss 从倒地直接打到死。
> 复刻时要不要保留这一点是个**设计选择**：
> 保留则手感与原版一致（但会让 Boss 战变简单），
> 加上无敌帧则更「合理」但偏离原版。

> **关于「伤害变高 + 出现贴图」的现象**：力量掷出高值（社区叫「暴击」）时
> **原版没有任何专属特效或 UI 提示**，只能实测伤害发现（社区实测结论 `[社区分析]`）。
> 玩家看到贴图的真实来源是**击倒反馈**：
> - 击倒敌人时弹出**漫画拟声标签「カタ（Ka Ta）」**（ROM 标签系统 `[ROMDATA]`）；
> - 每次命中有**打击火花**，部分攻击带**血花 / 残肢**贴图（见 [08 §9](./08-rom-data-tables.md#9-可破坏物件尺寸)）；
> - 「高伤害 + 贴图」同时出现的真正原因是：**连击终结段 / 冲刺攻击等
>   高伤且带击倒的攻击**。
>
> 复刻时**不要把贴图做成「暴击指示器」** —— 原版暴击是纯隐藏数值。

### 难度具体改变了什么（汇总）

**已证实、可直接实现的：**

| 影响项 | 规则 | 可信度 |
| --- | --- | --- |
| 敌人 HP | 基础 HP 之上追加难度加成 `0/32/66/100/0/66/132/200`（第 4 档回落到 0，异常待核对，见 [08 §4](./08-rom-data-tables.md#难度对敌人-hp-的加成)） | `[ROMDATA]`／`[MOD引原版]` |
| 副 Boss HP | 8 档中 7 档为 200，**最高难度档为 500**（另一版补丁写作 600） | `[ROMDATA]`／`[MOD引原版]` |
| 玩家力量（暴击）掷值范围 | 力量表按难度分 4 块：满血基准 32；**只有最高难度块才可能掷出 64（伤害翻倍）**，最低难度块甚至含低于基准的 24/28。8 档难度 → 4 块的具体映射 `[待核对]` | `[ROMDATA]` |

**没有证据表明受难度影响（复刻时先不要臆加）：**

| 影响项 | 现状 |
| --- | --- |
| 敌人 AI / 攻击频率 | 无原版数据。改版作者为「提升难度」专门写了让**敌人攻击更频繁**的 hack（GameDifficultyImprovement），侧面说明**原版难度大概率不改 AI**，只靠 HP 加成 + 力量表拉高压力 |
| 敌人攻击伤害 | 逐敌伤害数值本身缺失 `[待核对]`，是否随难度变化也未知 |
| 敌人数量 / 刷怪配置 | 「多人时敌人更多」由刷怪记录的**人数标记**驱动，与难度无关；难度是否改动刷怪配置无记录 |
| 时间限制 / 掉落 / 分数 | 无任何难度相关记录 |

> 复刻时建议把难度做成一个**只查三张表**的参数：敌人 HP 加成表、
> 副 Boss HP 表、力量表块索引 —— 这正是当前有 ROM 证据支撑的全部影响面；
> 其余「难度更高敌人更凶」的手感如需强化，属于复刻的自定义扩展，应与原版行为区分标注。

复刻时建议把「随人数变化的敌人生成数量」做成关卡配置表里的一个标记，
而不是写死在生成逻辑里 —— 原版就是这么做的，见
[05-stages.md](./05-stages.md#刷怪记录结构16-字节)。
